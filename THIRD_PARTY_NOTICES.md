# Third-party material

The MIT license applies to this project's original patch code, tools and documentation. It does not license either visual novel or its executable, scenario scripts, graphics, voices, music, fonts, saves or engine implementation.

The source package includes the original-code WinMM proxy and its export-name/ordinal catalog. It does not include either game, a Wine prefix, Wine system DLLs, Japanese fonts, extracted scenario corpora, or the generated MSC/MGR overrides. The resource generator reads the user's own game Copy and creates those overrides locally.

Research and development used Ghidra, Wine/Proton, Clang/LLD, and GARbro's MPK/MGR format research. These are separate projects with their own licenses. They are not relicensed by this project. Runtime audio and visual comparisons used the user's own installed games.

The target title is published by Propeller. The Itsusora reference was found to use BGI/Ethornell; it is a presentation reference, not a source of transplanted executable code or copied window assets. The rounded panel is generated mathematically from measured geometry and opacity.
